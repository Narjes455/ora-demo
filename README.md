# أورا: نسخة عرض

نسخة عرض تفاعلية من **أورا**، نظام لإدارة المنشآت: الموظفين، العمالة، الحضور، العقود، الفواتير، وكشوف الحساب.

**جرّبها:** https://narjes455.github.io/ora-demo/

- اختر دوراً (الإدارة التنفيذية، الموارد البشرية، المحاسبة، إدخال البيانات) وشوف كيف تتغير الأقسام والصلاحيات.
- الحضور يتسجل تلقائياً مع الدخول، والانصراف مع «إغلاق النظام».
- سجّل سداد فاتورة وشوفه ينعكس على كشف حساب العميل.

كل البيانات وهمية، وتتصفّر عند تحديث الصفحة. هذي الصفحة عرض لفكرة النظام وواجهته، أما النسخة الفعلية فهي تطبيق سطح مكتب بـ Python متصل بقاعدة بيانات سحابية، وكودها خاص.

المطوّرة: نرجس العمري، [GitHub](https://github.com/Narjes455)
